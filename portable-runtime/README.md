# Vorbereitete Laufzeit

Die vollständige Linux-x86_64-Laufzeit liegt als Datei `vitalux-linux-x86_64.tar.xz` in diesem Verzeichnis. Sie enthält Python 3.12, PySide6, psutil und ergänzende Bibliotheken.

Das vollständige Test-ZIP unter `downloads/` enthält diese Datei ebenfalls. `ensure-runtime.sh` prüft vor dem Entpacken ihre feste SHA256-Prüfsumme und kann die Datei bei Bedarf aus demselben Repository nachladen.
