# Fertiges Testpaket

**[Vitalux Homeserver für Linux x86_64 herunterladen](https://github.com/PAAAUUULLOOOH/Homeserver-Dashboard/raw/refs/heads/main/downloads/Vitalux-Homeserver-v0.10.0-Test-linux-x86_64.zip)**

Die ZIP enthält die Anwendung, die sieben Designs, Python/PySide6/psutil, Startskripte und die Anleitung. Die Datei mit der Endung `.zip.sha256` enthält die SHA256-Prüfsumme. Nach dem Entpacken `START-HIER.txt` lesen.

Dieses Download-ZIP liegt direkt im Repository. Es ist kein Verweis auf den lokalen Chat-Arbeitsbereich. Docker muss auf dem Homeserver vorhanden sein; die eigentlichen Spieldateien werden bei Bedarf heruntergeladen.
